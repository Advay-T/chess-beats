# Chess Beats

A browser app that plays chess games as music: each move is a note, captures, checks and mates get
their own sounds, and a whole-game analysis shapes the arrangement. It ships a library of 1,003
famous games. The README holds the user-facing detail (sound tables, library categories).

## Run, test, deploy

- **Run:** open `index.html` (landing page) or `play.html` (player) in a browser. There is no build
  step and no server. Everything is plain scripts that also work from `file://`; only chess.js,
  Tone.js and the landing page's fonts come from a CDN.
- **Test:** `npm install` once, then `npm test` (note mapping, analysis, arrangement, PGN clean-up,
  and every library game replaying legally).
- **Regenerate data:** `npm run build:library` after changing `data/pgn/`, `games.js` or
  `tools/collections.js`; `npm run fetch:pgnmentor` re-downloads and re-picks PGN Mentor games;
  `npm run build:logo` re-renders `brand/*` from `knight3d.js` via `tools/logo/knight.html` (needs Chrome
  and internet).
- **Deploy:** GitHub Pages serves the root of `main` in **Advay-T/chess-beats**
  (https://advay-t.github.io/chess-beats/). Pushing to that `main` is the deploy.
- **Push only via the subtree split.** The `Code` folder is one git repo whose `origin` is FinEd-AI;
  never push the `chess-music` branch to `origin`. From the `Code` folder:
  `git subtree split --prefix=chess-music -b chess-beats-export`, then
  `git push chess-beats chess-beats-export:main`. If GitHub has edits the split lacks, merge them in;
  never force-push.

## Rules in effect

- **No build step, no framework.** Each file is a plain script (an IIFE that sets a `window.*`
  global; the logic files also `module.exports` for tests). Don't add bundlers, React or npm runtime
  dependencies.
- **Keep logic files pure** (`music.js`, `analysis.js`, `arrangement.js`, `pgn.js`): no DOM, no audio,
  so they stay testable in Node.
- **Sound mapping:** destination file → note in a pentatonic scale; rank → octave; piece → note
  length (pawn 16th up to queen half note); white = triangle synth on the left, black = FM synth on
  the right; capture = snare, check = cymbal, castling = chord, promotion = run, mate = final hit.
  The four layers (Motion, Harmony, Groove, Phase) each have an on/off switch. Every game starts at
  200 BPM with an auto key. Change the README's tables when this changes.
- **Look:** a dark theme. Ground `#0e0f13`; the white voice is light blue `#7fd3ff`, the black voice
  coral `#ff9470`, tension amber `#ffb347`. Tokens live at the top of `style.css` and
  `landing.css`; use them rather than new hex values.
- **Wordmark:** "Chess Beats" is Excon Regular (400) on every page (`.brand-word`), loaded from
  Fontshare's CDN. Never commit the font files: the licence forbids copies on public servers or repos.
- **Pieces are SVG** (`ChessPieces.use(code)` / `<use href="#pc-wK">`), never Unicode glyphs, which
  render differently on every OS.
- **Transport buttons** are `data-sling="primary|secondary"` (enhanced by `sling.js`, which keeps
  the original button and its listeners). Play/pause shows its icon via `data-playing` on `#btn-play`.
- **Motion:** animate `transform` and `opacity`; gate hover motion behind
  `(hover: hover) and (pointer: fine)`; every animation has a `prefers-reduced-motion` path.
- **Links:** the brand (logo + wordmark) goes to `index.html`; anything that opens a game goes to
  `play.html?game=<id>` (or `?pgn=pending`). Old `index.html?game=` links are forwarded by a
  script in `index.html`'s head. Keep that forwarder.

## Before you change things

- **Never edit generated files** (`library.js`, `data/pgn/pgnmentor-selected.pgn`, `brand/*`);
  change their sources and rebuild.
- **Audio must start from a user gesture** (iOS). Call `ChessAudio.init()` from the click or key
  handler, and `ChessAudio.ensure()` in playback loops to wake a context iOS suspended.
- **One knight:** change the knight's shape or look only in `knight3d.js`. `npm run build:logo` must still
  reproduce `brand/*` byte for byte unless you mean to change the logo; the live page's speed-ups
  (`fast`, `newton`, `profilePts`) are options that the stills don't use.
- **Pinned CDN versions:** chess.js 0.10.3 and Tone.js 14.7.77 (UMD builds that work from `file://`),
  and three.js 0.160.0 (an ES module, for the landing page's knight and the logo tool). Upgrading any
  of them is a deliberate change, not a drive-by.
- **Credits must stay:** Cburnett pieces (CC BY-SA 3.0, in the player's help dialog and the landing
  footer), the ChessPGN books (CC0), PGN Mentor, and GradFlow's GlassFold shader in `background.js`.
- The landing page's mixing desk plays real sounds by loading Tone.js, `music.js` and `audio.js` on
  demand (`landing.js`, `Sound`). Clicking a strip turns sound on; hovering plays only after that.
- `landing.js` copies the Immortal Game's moves and tension sparkline so the landing page doesn't load
  the 1.4 MB library. If the analysis changes, refresh that sparkline from `library.js`.
- Open work lives in `PLAN.md`.
